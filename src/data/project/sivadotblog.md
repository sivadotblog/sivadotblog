## High-level summary

siva.blog is the site you're reading right now — a personal blog and project log built on [AstroWind](https://github.com/onwidget/astrowind), running Astro v6 and Tailwind CSS v4. It generates a fully static site: no server, no database, just prerendered HTML shipped from GitHub Pages.

## Design

- **Content**: posts and projects are both Astro Content Collections, loaded from markdown/MDX under `src/data/post/` and `src/data/project/` via the v6 Content Layer API's `glob()` loader. Post categories stay as flat internal metadata rather than a nav-level taxonomy.
- **Styling**: Tailwind v4, configured CSS-first (`@theme`, `@utility`, `@plugin`) in `src/assets/styles/tailwind.css`, with light/dark theme variables in `CustomStyles.astro` and class-based dark mode.
- **Routing**: file-based Astro pages, including dynamic `[...page]` pagination for the post list and `[category]` / `[tag]` taxonomy pages, plus a parallel `/projects/` index and `/projects/[slug]/` detail routes for this project collection itself.
- **Images**: local images go through `astro:assets` (Sharp-optimized); remote images route through Unpic CDN.
- **Build**: `npm run build` produces a static `dist/`, compressed and sitemap-indexed at build time, deployed as a static site.
